# Taste results review

## Changes and rules

Personal result at /taste-test/result: archetype or honest interim result, evidence counts, separate genre/style/publication-era affinities, up to twenty unique available books with supported reasons, reading-list actions and optional continuation. The rules were written before code in taste-results-design.md. Subject/audience traits are unavailable in the approved v1 evidence and are not inferred. Low ratings reduce affinity; missing traits remain missing. Result recommendations use the exact shrunk signed profile shown on this page. The older homepage/guest ranking algorithm is not rewritten by this change.

New rounds offer 10, 15 and 30 explicit ratings; results can be viewed at ten answers or on exhaustion. Ten/fifteen rounds can be explicitly extended. Existing twenty-rating rounds, scores, offers and completion remain intact. The new API is versioned; the old five-argument API remains available with its twenty-book default. Search/return-to and existing reading-list controls are reused. Result book links return to the exact safe result path, not A–Z Browse.

Source confirms that the completed old round showed only a link, not inline book cards. Server load failures were masked as an empty unauthenticated recommendation list; an explicit unavailable state now distinguishes that failure. The requested screenshot was not supplied, so its exact root cause is not asserted.
